## res://scripts/element_grid/tile_packet.gd

The unified per-tile packet (world.md §2), stored structure-of-arrays:
one PackedByteArray column per field, one row per tile. The tile index
is the row number.

- `_init(p_w: int, p_h: int) -> void` - Allocate the w×h grid: every column resized, ledger zeroed.
- `clear() -> void` - Zero every column and the ledger.
- `idx(x: int, y: int) -> int` - Flat-array index of tile (x, y).
- `in_bounds(x: int, y: int) -> bool` - True if (x, y) lies inside the grid.
- `xy_of(i: int) -> Vector2i` - Tile (x, y) of flat index i.
- `get_terrain(i: int) -> int` - Terrain value at tile i.
- `set_terrain(i: int, t: int) -> bool` - Set terrain at tile i; true when the value changed (GridStone's signal rides on this).
- `get_sub(i: int, kind: int) -> int` - Subtile nibble at tile i; kind: 0 stone_s, 1 soil_s, 2 ice_s (matches SUB_SINK order).
- `set_sub(i: int, kind: int, n: int) -> int` - Set a nibble column, book the popcount delta; returns the capacity deficit created (ejecting that overflow is the flow engine's job, world §3).
- `pool_capacity(i: int) -> int` - Full-solid terrain = 0, otherwise 255 minus 64 per solid subtile (stone + soil + ice).
- `get_pool(i: int, m: int) -> int` - Units of material m held at tile i.
- `pool_total(i: int) -> int` - Units of every material held at tile i.
- `pool_free(i: int) -> int` - Headroom left at tile i (capacity minus total).
- `_add_units(i: int, m: int, amount: int) -> void` - The ONLY place pool bytes are mutated. Pre-clamped by callers.
- `add_pool(i: int, m: int, amount: int) -> int` - Add up to amount units of m; returns units accepted (refused units are NOT destroyed -- the caller ejects them by flow rules).
- `take_pool(i: int, m: int, amount: int) -> int` - Remove up to amount units; returns units actually taken.
- `set_pool(i: int, m: int, v: int) -> int` - Tool path (paint/erase): force tile i's m toward v; returns spill (units refused). Never destroys other materials or pushes past capacity (over-budget stays until flow ejects).
- `_book(row: int, delta: int) -> void` - Apply delta to the booked total of one ledger row.
- `mat_total(m: int) -> int` - Fresh recount of one pool column.
- `assert_all() -> bool` - Double-entry check: booked totals vs fresh recounts, plus the per-tile pool constraint. Called at the end of every tick.
- `drain_lightest(i: int, amount: int) -> int` - Remove up to amount units of the single lowest-density material present at tile i; returns units taken.
- `clear_mat(m: int) -> void` - Zero one pool column, booking the removal. (Clear/reset path.)
